SONG KEY SYSTEM — النسخة النهائية

الملفات:
- song_key_system_FINAL.html
- server_FINAL.js
- package_FINAL.json

التشغيل:
1. استضافة تدعم Node.js.
2. ضع متغير البيئة SONG_ADMIN_TOKEN بكلمة سر قوية.
3. شغّل npm start.
4. افتح الدومين.

المزايا الحقيقية:
- زائر فريد عبر Cookie.
- زوار اليوم والزوار النشطون.
- إصدار مفاتيح من السيرفر.
- المفتاح صالح 24 ساعة.
- استخدام مرة واحدة عبر /api/validate-key.
- Rate limit: 10 طلبات لكل زائر خلال 10 دقائق.
- إحصائيات الإدارة محمية بـ Bearer Token.

مهم: هذا نظام مفاتيح خاص بك، وليس أداة لتجاوز حماية أنظمة مفاتيح خارجية.
لا تضع SONG_ADMIN_TOKEN داخل HTML.
